# 動画中国語② 電子教材

日本の大学生向けの中国語聴解教材です。第一課の前に、原教材に基づくHSK（四級）聴解の説明と、この教材の使い方を掲載しています。全5課の表現・単語・HSK4級聴解練習を、付属のMP3音声とともに閲覧できます。解答後に正誤と聴解原文を確認できます。

## 使い方

1. `index.html` を Chrome、Edge、Firefox、Safari などのブラウザーで開きます。GitHub Pages からも利用できます。
2. 「HSK聴解の説明」で出題形式を確認してから課を選び、「表現・単語」で意味を確認します。表現カードまたは単語カードのどこを押しても発音を聴けます。単語の中国語・ピンイン・日本語訳は個別に表示／非表示を切り替えられます（初期値は中国語と日本語訳を表示、ピンインを非表示）。再生中に同じカードを押すと一時停止し、もう一度押すと再開します。画面下のプレーヤーには状態表示と「停止」ボタンがあり、「再生速度」で0.5～2倍に変更できます。初期値は1倍です。
3. 「聴解練習」で音声を聴き、解答を選びます。各部分の小問は開くたびに順番が変わり、同じ音声を使う２問は一緒に表示されます。選択はその端末のブラウザーに保存されます。
4. 正解なら励ましの言葉が表示されます。不正解なら正解と聴解原文が表示され、その問題だけ再挑戦できます。正解時も「聴解原文を見る」を開いて確認できます。「この部分をもう一度」で解答を消し、並び替えて練習できます。

正誤判定は提供された「動画2回答.docx」の解答表示を基にしています。同資料の一部には聴解原文や選択肢との食い違い、未記入の解答があったため、原文を照合して補正しました。複数の答えが成り立つ設問は、いずれも正解として扱います。第一課の第43問、第三課の第35問、第五課の第29問は、選択肢に問題があったため学習用に書き直しました。

## 内容

- 5課、表現37項目、単語182項目、聴解問題225問
- MP3音声420ファイル。表現・単語・聴解問題の3系列
- 元教材PDF: `assets/動画2テキスト.pdf`
- HTML / CSS / JavaScript の静的サイト。外部ライブラリやサーバーは不要

教材と音声は提供された原資料を電子教材用に再構成しました。PDF由来の明らかな改行・選択肢ラベルの誤りを修正しています。著作物の公開については提供者から許諾確認済みです。再利用条件は本リポジトリに明示されていません。

## 修正・保守

課ごとの表現・単語・設問・正解・聴解原文は `data/lessons/lesson-01.js` ～ `lesson-05.js` にまとめています。修正手順と音声ファイルの対応は [维护指南.md](维护指南.md) を参照してください。任意で `python tools/check_content.py` を実行すると、解答と音声の参照を確認できます。

## GitHub Pages

リポジトリの Settings → Pages で `Deploy from a branch`、`main`、`/(root)` を選ぶと公開できます。すべて相対パスなので、プロジェクト用 URL でも動きます。

GitHubに公開する場合はZIPを解凍し、中のファイルとフォルダーをすべてリポジトリのルートにアップロードしてください。ZIPファイルだけをアップロードしてもGitHub Pagesでは表示できません。

第五課の単語音声には教材の語彙表より1ファイル多い録音があり、誤った単語への割り当てを避けています。
